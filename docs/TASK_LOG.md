# Журнал задач

Журнал ведётся по порядку выполнения задачи из `CLAUDE.md`. Для каждой задачи бэклога (`docs/BACKLOG.md`) создаётся раздел до начала реализации; ответы разработчика фиксируются до кода, итог дописывается при закрытии.

```
## E06-02. Название задачи из бэклога

- Взята в работу: YYYY-MM-DD
- Опорные разделы: ТЗ …; Архитектура …; Кейс п. …

### Критические вопросы и ответы

| # | Вопрос | Ответ разработчика | Влияние на реализацию |
| --- | --- | --- | --- |
| 1 | … | … | … |

(Если вопросов нет: «Критических вопросов нет — обоснование».)

### Итог

- Сделано: …
- Проверено: какие проверки запущены и результат (test-engineer, security-audit, pre-merge-check)
- Осталось / отложено: …
- Закрыта: YYYY-MM-DD, коммит: хэш или «пуш не подтверждён»
```
