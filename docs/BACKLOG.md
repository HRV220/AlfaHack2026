# Бэклог задач — Умный кредитный кабинет предпринимателя

Декомпозиция для команды разработки (Frontend, Backend, DS/ML, Product/UX/BA). Источник: ТЗ v4.1, Архитектура (раздел 19 — план на 7 дней), `docs/contracts/`. На момент составления в репозитории есть только документация и контракты — ни один сервис не реализован.

Правила использования:

- **Приоритет** — колонка «Пр.» из ТЗ (M / S1…S11 / C). Must не урезается; Should делаются по порядку S1→S11 и урезаются в обратном порядке при нехватке времени (ТЗ 3.1).
- **День** — целевой день из плана раздела 19 архитектуры; ориентир, не жёсткий дедлайн.
- **Req** — ID требований ТЗ, которые задача закрывает.
- Задачи — кандидаты на тикеты в трекере команды (Jira/Linear/GitHub Issues/Trello — на усмотрение команды, в репозитории трекер не настроен).
- Контракты (`docs/contracts/`) уже заморожены v1.0.0 — задачи реализации должны соответствовать им, а не придумывать поля заново. Любое изменение контракта — через генераторы (`docs/contracts/tools/`), см. `docs/contracts/README.md` раздел 8.
