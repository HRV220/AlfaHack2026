# Синтетический реестр (`fixtures/registry/`)

Вымышленные карточки компаний «по образцу ЕГРЮЛ/ЕГРИП» (РШ-6, REG-05). Реальные ЕГРЮЛ/ЕГРИП и
DaData не используются; все названия, ФИО и адреса придуманы.

Формат файла — `RegistryData` из `docs/contracts/schemas/domain.schema.json`, имя файла — ИНН.
Init-контейнер загружает карточки в `core.registry_snapshot` (upsert по ИНН, E02-06.3) и
отклоняет каталог целиком, если карточка не проходит схему или контрольную сумму ИНН.

(не меньше 30 карточек, E03-03) и итоговые данные DC-1…DC-6 (E03-04) заменят их.
